## Naming Convention

- **Folders**: `XX_category/vX.X/` (numbered prefix, version subfolder)
- **Files**: `snake_case.md` (Mermaid source) + `snake_case.png` (exported image)

## Export Instructions

1. Open `.md` file in VS Code with Mermaid Preview extension
2. Or use Mermaid Live Editor: https://mermaid.live
3. Export as PNG and save in same folder with matching name
